# Liwei-Lu
Quick Start Guide: Create a Private GitHub Repository with a README
Platform: Desktop browser, English interface
Audience: First‑time GitHub users who have already logged into their GitHub account
Prerequisites: A valid GitHub account and permission to create new repositories
Steps
1. On the GitHub homepage, click the + dropdown menu at the top right corner, then select New repository.
2. In the Repository name box, type your desired repository name (for example,  Liwei‑Lu ). Check the prompt to confirm the name is available.
3. Under Choose visibility, select Private, so only you and invited collaborators can access this repo.
4. Toggle on the Add README option. Leave  .gitignore  and license as default if you do not need them for now.
5. Click the green Create repository button at the bottom of the page.
Result Check
After creation, you will be redirected to the repository main page. Verify that:
- The repository name you entered is shown at the top
- The visibility tag displays Private
- A  README.md  file appears in the file list and its content preview is visible on the page
Later use: This private repository can store your project files, documentation and track version changes.
